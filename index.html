GAME 01

詐欺耐性診断ゲーム

いろいろな場面の質問に答えて、 あなたの詐欺への注意ポイントをチェック！ 遊びながら、自分がだまされやすい場面を知ることができます。

🔎
GAME 02

怪しいポイントを探せ！

詐欺メッセージの中から、 「ここが怪しい！」というポイントを探そう。 全10問からランダムで5問に挑戦します。

🎮 ゲームをプレイ
↔️
GAME 03

本物？ニセモノ？仕分けパズル

届いたメッセージが本物なのか、 詐欺なのかを見分けよう。 カードを左右にスワイプして仕分けします。

🎮 ゲームをプレイ
🧩
GAME 04

詐欺メッセージ復元パズル

バラバラになったメッセージのパーツを 正しい順番に並べて復元しよう。 メッセージの流れから怪しいポイントを学べます。

🎮 ゲームをプレイ

⚠️ 怪しいメッセージが届いたら、 すぐに返信・送金せず、落ち着いて確認しましょう。
